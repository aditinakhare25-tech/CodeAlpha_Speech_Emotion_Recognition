CodeAlpha Speech Emotion Recognition

Project Overview

This project recognizes human emotions from speech audio recordings using a deep learning model.

Objectives

- Extract MFCC features from speech audio.
- Train an LSTM neural network to classify emotions.
- Evaluate model performance using accuracy and a confusion matrix.
- Predict emotions from audio recordings.

Technologies Used

- Python
- Librosa
- NumPy
- TensorFlow / Keras
- Scikit-learn
- Matplotlib

Dataset

RAVDESS Speech Dataset

Dataset link: https://zenodo.org/records/1188976

Model

Long Short-Term Memory (LSTM) neural network using MFCC audio features.

Project Files

- "speech_emotion_recognition.py" — prediction script
- "speech_emotion_lstm.keras" — trained model
- "label_encoder.pkl" — emotion label encoder
- "model_config.json" — model configuration

Results

Model accuracy and classification results were evaluated using the test dataset. Refer to the project notebook for the actual results.
